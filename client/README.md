# Telegram PIN Login — клиент

Самостоятельное настольное приложение на Python и Flet. Папку `client` можно перенести в другое место: для запуска ей не нужны исходники сервера или бота.

Клиент обращается к серверу по HTTP. Сначала отдельно запустите сервер, затем этот клиент. Закрытие окна клиента не останавливает сервер.

## Установка на новом компьютере (Windows)

Нужны Python 3.12 и GNU Make для команд Makefile. Все команды выполняются в PowerShell **из папки client**. На настроенном ноутбуке переходите к разделу запуска.

```powershell
make install
```

Команда создаст отсутствующее окружение, установит зависимости и создаст `.env` из примера, если его ещё нет. Затем заполните настройки ниже. Существующий `.env` не перезаписывается.

Вариант без Make:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

На текущем компьютере `.venv` уже подготовлено; повторно создавать его не нужно. При первом запуске Flet может потребоваться интернет для загрузки нативного окна.

## Настройки

В `.env` задайте только клиентские параметры:

```dotenv
API_BASE_URL=http://127.0.0.1:3000
BOT_USERNAME=your_bot_username
```

`API_BASE_URL` — адрес работающего API. `127.0.0.1` подходит, если сервер работает на том же компьютере. `BOT_USERNAME` — username вашего Telegram-бота без `@`, вместо примера.

Токен бота и внутренние серверные ключи клиенту не нужны. `.env` не публикуется в Git.

## Запуск через Makefile (Windows)

Проверьте доступность GNU Make командой `make --version`. На Windows с winget его можно установить командой `winget install --id ezwinports.make --exact --source winget`, затем открыть новый терминал. Если команда не появилась во встроенном терминале, полностью перезапустите IDE. Makefile использует `cmd.exe`.

Сначала запустите сервер и дождитесь **«Сервер готов»**. В отдельном терминале из папки `client` выполните:

```powershell
make run
```

Из общей папки используйте `make -C server run` в первом терминале и, после готовности сервера, `make -C client run` во втором. Для остановки клиента закройте окно; для остановки сервера нажмите `Ctrl+C` в его терминале.

На новом компьютере сначала выполните `make install`, затем заполните `.env`.
Существующий `.env` и окружение при этом сохраняются. `make help` покажет команды.

## Другие способы запуска

Дважды нажмите `start.bat` либо выполните:

```powershell
.\start.bat
```

Альтернативный запуск через Python:

```powershell
.\.venv\Scripts\python.exe run.py
```

В окне появятся QR-код и кнопка перехода к боту. Откройте бота, отправьте `/start`, введите новый PIN и нажмите «Войти». PIN одноразовый и действует 15 минут до первого использования.

После входа доступны профиль и отправка сообщения администратору. Для завершения закройте окно. Сервер продолжит работать независимо.

## Проверка работы

1. Откройте бота через QR или кнопку. Отправьте `/start` и войдите по полученному PIN: приложение должно показать ваш профиль.
2. Отправьте тестовый текст администратору. Проверьте подтверждение в приложении и фактическое получение сообщения в Telegram с правильным отправителем.
3. Закройте и снова запустите клиент. Использованный PIN должен отклоняться; запросите новый через `/start` и войдите с ним. Новый `/start` отменяет предыдущий неиспользованный PIN.

Если сообщение не пришло, на сервере проверьте `ADMIN_CHAT_ID` и что администратор уже написал боту. Ответы администратора из Telegram обратно в приложение не доставляются.

## Структура

- `app/main.py` — интерфейс;
- `app/api_client.py` — HTTP-запросы к API;
- `run.py`, `Makefile`, `start.bat` — запуск только клиента;
- `requirements.txt` — зависимости;
- `.env.example` — пример настроек;
- `.venv/` — единственное Python-окружение клиента.
