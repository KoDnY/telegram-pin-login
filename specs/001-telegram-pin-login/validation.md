# T020 — результаты локальной проверки

Дата: 2026-10-20. Проверка выполнена на Windows в рабочем каталоге проекта.

## Выполнено

| Проверка | Результат |
| --- | --- |
| `npm --prefix api run build` | Успешная компиляция TypeScript |
| `npm --prefix api test` | 33/33 теста пройдены |
| `bot/.venv/Scripts/python.exe -m pytest bot/tests -q` | 21/21 тест пройден |
| `client/.venv/Scripts/python.exe -c "from client.app.main import LoginApp; import flet"` | Импорт клиента и Flet успешен |
| `bot/.venv/Scripts/python.exe tests/local_smoke.py` | Сквозной локальный HTTP-сценарий пройден |

Сквозной тест запускает скомпилированный Express настоящим дочерним Node-процессом и приложение aiohttp с настоящим Dispatcher/Router aiogram. Реальные Bot API-вызовы заменены тестовой Telegram-сессией; регистрация webhook отключена только в тесте. PIN проходит через `/telegram/webhook` → обработчик `/start` → настоящий API → Telegram-ответ. Вход и сообщение выполняет настоящий `client.app.api_client.ApiClient` по HTTP. Текст проходит Express → `/internal/messages` бота → перехваченный `SendMessage`.

Проверены два независимых пользователя, правильные профили, отсутствующие необязательные поля, одноразовость PIN, подпись отправителя и текст сообщения, подтверждённый успех, ошибки 502/504 без повторной отправки, прекращение действия сессии после перезапуска реального API-процесса. Собранный stdout/stderr API не содержит тестовых внутренних ключей, webhook-secret, BOT_TOKEN, PIN или токенов входа. Все запущенные тестом процессы и сессии закрыты.

Модульные проверки дополнительно охватывают истечение PIN на точной границе 15 минут, замену старого PIN, ведущий ноль, конкурентное потребление одного PIN, авторизацию внутренних маршрутов, неверные профили и текст, защиту от подмены отправителя, webhook-secret, дедупликацию update_id и завершение жизненного цикла.

## Ограничения и внешняя проверка

На момент локального прогона T020 полная демонстрация через настоящий Telegram и ngrok **не была выполнена**: пользователь сообщил, что бот BotFather и ngrok ещё не настроены. Реальные секреты не использовались. Нет подтверждения регистрации публичного webhook, доставки настоящего PIN в Telegram или сообщения настоящему администратору. Это требует настройки по quickstart и ручного прохождения сценария.

Импорт Flet подтверждает совместимость загрузки модулей, но не заменяет визуальную проверку desktop-окна: ввод PIN, отображение аватара и заглушек, состояния кнопок и сообщений ошибок нужно проверить при ручном запуске.

T020 завершён как локальная проверка реализации с явно перечисленными внешними ограничениями; это не утверждение об успешном Telegram/ngrok end-to-end запуске.
