# Подтверждённые ограничения проекта

Источник: BE_task01.pdf и последующие прямые уточнения пользователя. Этот файл сохраняет ограничения реализации отдельно от функциональной спецификации.

- Клиент: Python + Flet, отдельное приложение на компьютере.
- API: TypeScript + Express; проект не должен состоять только из Python.
- Telegram-бот: Python + aiogram, получение событий через webhook обязательно.
- Использовать ngrok для публичного доступа к локальному обработчику вебхука.
- В исходном ТЗ указаны auth(key) с возвратом пользователя и health() с возвратом статуса. Конкретные HTTP-методы и формат сообщений относятся к планированию.
- База данных и SQLAlchemy не нужны, согласно последнему уточнению пользователя.
- Использовать готовые MCP и Skills при разработке; собственные создавать не требуется. Конкретный набор ещё не выбран; для спецификации уже применяется speckit-specify.
- Тематика Majestic и финансовый дневник исключены.
- PIN: шесть цифр, 15 минут, одноразовый; новый /start отменяет предыдущий PIN.
- Пользователь просит задавать вопросы до добавления требований. Код в рамках спецификации не создаётся.
